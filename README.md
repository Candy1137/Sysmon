# 🔍 Sysmon Beginner's Guide

> A structured, beginner-friendly learning guide for understanding and using **Sysmon (System Monitor)** — a powerful Windows endpoint monitoring tool by Microsoft Sysinternals.

---

## 📌 What is This Repo?

This repository is a personal learning guide documenting everything I explored while learning Sysmon from scratch. It's organized to help **beginners in cybersecurity**, Blue Team, SOC, and DFIR get started quickly.

---

## 📁 Folder Structure

```
sysmon-beginner-guide/
├── 01-introduction/         → What is Sysmon & why it matters
├── 02-installation/         → How to install & set up Sysmon
├── 03-event-ids/            → Key Event IDs explained
├── 04-configuration/        → Writing & using config files
├── 05-use-cases/            → Real-world detection scenarios
└── resources/               → Useful links, tools & references
```

---

- Beginners in **cybersecurity**
